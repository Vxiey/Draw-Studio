# Image Draw Bot v1.0.144-rc4 — Get started and setting help

- A six-section Get started guide explains the first drawing, target profiles, calibration, preview and modes, starting/stopping, and troubleshooting.
- Paint and browser/manual start instructions reflect their different workflows.
- Keep the guide open beside the app, use Back/Next or select a topic. The content scrolls on smaller windows.
- Settings have clickable ? help and hover explanations, with practical tradeoffs for quality, speed, brush width and CPU/GPU resources.
- Tooltips respond to focus, stay within desktop bounds and close when their control is destroyed.
- Help and Get started open the same guide. Reading help does not change settings or start drawing.

Includes native Windows guide navigation and tooltip lifecycle checks.
