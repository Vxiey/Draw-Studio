## Reddit post

I have been building **Image Draw Bot**, a Windows desktop app that recreates source images by controlling real drawing tools instead of generating a new image.

It can target Microsoft Paint, Gartic Phone, Skribbl.io and similar canvases. The planner uses connected colour regions, Fill where safe, adaptive brush sizes, contours, correction passes and a Pixel Accurate mode. Preview and estimated draw time are based on the same planner used for the real draw path.

The project is source-available and Windows builds are published on GitHub:
https://github.com/Vxiey/Image-Draw-Bot

I would especially like feedback on real target compatibility, drawing quality, calibration and performance. If you test it, screenshots, logs and reproducible failures are useful.

## Sharing checklist

- Show the actual app or a real drawing result first.
- Link directly to the repository or latest release.
- State which targets are supported.
- Mention one or two differentiators instead of listing every feature.
- Ask for testing/feedback rather than only asking for stars.
- Answer comments and bug reports quickly after launch.
- Re-share meaningful releases with a concrete before/after improvement.
