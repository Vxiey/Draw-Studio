# Updates and release history

Current published release: [v1.0.144-rc5](https://github.com/Vxiey/Image-Draw-Bot/releases/tag/v1.0.144-rc5). It fixes blocking Paint color-dialog activation and recovery after interrupted RGB calibration. It also includes the new Get started guide and clickable setting help. Recent rc2/rc3 releases introduced unified icons and explicit Windows taskbar identity.

## Update the installed app

Use **Check updates / install** to check published releases, or download the current Setup from [Installation](Installation). Close the running app before manually installing the update. Confirm the new version after launch.

For portable use, extract the complete new ZIP into its own folder and launch its ImageDrawBot.exe. Do not mix old and new supporting files.

## Still seeing an old name or icon?

Check the running version and launch path first. An old pinned shortcut may still point to another installation or extracted folder. Current packages use Image Draw Bot and ImageDrawBot.exe. If the problem remains on the current version, include a screenshot, version and installer/portable choice in a report.
