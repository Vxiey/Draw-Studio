# Controls, safety and privacy

**Esc** stops drawing immediately. **F6** pauses/resumes. Keep the target visible and leave the mouse alone during automation.

Canvas bounds, clipping and runtime checks help constrain drawing to the selected area. Incorrect calibration can still produce an incorrect result: stop and investigate unexpected behavior.

## Know which actions affect the target

| Action | Effect |
| --- | --- |
| Get started / setting help | Read instructions; does not start drawing or change settings |
| Build preview | Plans a simulation without drawing on the target |
| Setup wizard | Reports current profile requirements |
| Test mouse / Fast Dry run | Can move the pointer; Dry run sends no drawing clicks |
| Small test | Draws a small real sample |
| Custom color palette for picture | Operates Paint's color controls |
| Prepare Paint & draw | Prepares Paint, then starts drawing |
| Armed browser/drop modes | May start drawing after image import |
| Auto clear target canvas | Can erase existing artwork before a full drawing |

## Local processing

There is no telemetry, automatic crash-report upload or remote bug-report backend. Runtime reports and diagnostics stay local unless you share them. Explicit features such as loading an image URL, checking updates or installing dependencies use the network.
