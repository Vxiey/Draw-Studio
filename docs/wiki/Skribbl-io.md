# Skribbl.io setup

1. Open a drawable canvas and select the matching Skribbl.io profile.
2. Keep browser size and zoom stable.
3. For a manual first attempt, turn **Browser One-Click Mode off** and leave drop-start modes unarmed before loading an image.
4. Run **Auto setup browser** or **One-click Setup + Verify** where available. Verify the palette and select only the drawable canvas if manual selection is needed.
5. Build a fresh preview. Choose a time budget that leaves room before the round ends.
6. Follow the setup messages, then **Unlock full drawing → Start drawing**.

If the palette or layout changes, verify calibration again. **Esc** stops immediately. Use automation only in sessions where it is permitted.
